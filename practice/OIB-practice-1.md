### Теоретическая база и расчетные формулы

**1. Комбинаторная и максимальная энтропийная стойкость**

Мощность пространства возможных паролей длины $L$ над алфавитом мощности $A$:

$$N = A^L$$

Максимальная энтропийная стойкость (мера Хартли):

$$H_{max} = \log_2(N) = L \cdot \log_2(A)$$

*Примечание для расчетов на калькуляторе:* $\log_2(x) = \frac{\ln(x)}{\ln(2)}$.

**2. Фактическая энтропия источника, избыточность и неравенство Йенсена**

Фактическая энтропия Шеннона для источника независимых символов с вероятностями $p_i$:

$$H(X) = -\sum_{i=1}^{k} p_i \log_2 p_i \quad \text{(в битах/символ)}$$

Информационная избыточность:

$$R = 1 - \frac{H(X)}{\log_2 k}$$

Для строгого доказательства максимума энтропии при равномерном распределении применяется неравенство Йенсена для строго вогнутой функции $f(x) = \log_2(x)$:

$$\sum_{i=1}^{k} p_i f(x_i) \le f\left(\sum_{i=1}^{k} p_i x_i\right) \implies \sum_{i=1}^{k} p_i \log_2\left(\frac{1}{p_i}\right) \le \log_2\left(\sum_{i=1}^{k} p_i \cdot \frac{1}{p_i}\right) = \log_2(k)$$

**3. Двукратное использование OTP (Two-Time Pad)**

Шифр Вернама: $C = M \oplus K$. При шифровании двух сообщений одним ключом: $C_1 = M_1 \oplus K$ и $C_2 = M_2 \oplus K$.
Свойства условной энтропии гласят, что для совершенно секретного шифра должно выполняться $H(M \mid C) = H(M)$. Если это равенство нарушается, шифр уязвим.

**4. Энтропия Марковского источника (источника с памятью)**

Для цепи двух состояний Маркова (состояния $S_1, S_2$) с матрицей переходов $P_{i,j} = P(X_t = j \mid X_{t-1} = i)$ стационарное распределение $\pi = (\pi_1, \pi_2)$ находится из системы уравнений:

$$\begin{cases} \pi_1 = \pi_1 P_{11} + \pi_2 P_{21} \\ \pi_2 = \pi_1 P_{12} + \pi_2 P_{22} \\ \pi_1 + \pi_2 = 1 \end{cases}$$


Предельная энтропия источника с памятью:


$$H_{\infty}^{Markov} = \sum_{i} \pi_i H(X \mid S_i) = \pi_1 \left( -P_{11}\log_2 P_{11} - P_{12}\log_2 P_{12} \right) + \pi_2 \left( -P_{21}\log_2 P_{21} - P_{22}\log_2 P_{22} \right)$$

**5. Min-энтропия и расстояние единственности**

Min-энтропия (Реньи при $\alpha \to \infty$) определяет стойкость к угадыванию наиболее вероятного значения:


$$H_{\infty}(X) = -\log_2(\max p_i)$$


Расстояние единственности $U$ (в символах) — минимальный объем шифротекста, при котором ключ определяется однозначно (отсеиваются ложные ключи из-за избыточности открытого текста):


$$U = \frac{H(K)}{R \cdot \log_2 \vert{}A\vert{}}$$

### Пример выполнения расчетной работы (Вариант 0)

**Исходные данные (Вариант 0):**

* **Задания 1, 4:** $L = 10$, $A = 52$. Распределение для $k=3$ символов: $p_1 = 0,6, p_2 = 0,3, p_3 = 0,1$.
* **Задание 3:** переходные вероятности $P_{11} = 0,7$, $P_{22} = 0,4$.
* **Задание 5:** AES-128 ($H(K) = 128$), $A_{txt} = 32$, $R = 0,68$.

#### Задание 1. Комбинаторная стойкость, энтропия, избыточность и Йенсен

**1.1 Комбинаторный расчет:**

$$N = 52^{10} \approx 1,44 \cdot 10^{17}$$
$$H_{max} = 10 \cdot \log_2(52) \approx 10 \cdot 5,7004 = 57,004 \text{ бит}.$$

**1.2 Энтропийный расчет и избыточность:**

$$H(X) = -(0,6 \log_2 0,6 + 0,3 \log_2 0,3 + 0,1 \log_2 0,1)$$
$$H(X) = - (0,6 \cdot (-0,737) + 0,3 \cdot (-1,737) + 0,1 \cdot (-3,322)) = 0,442 + 0,521 + 0,332 = 1,295 /text{ бит/символ}.$$

Избыточность $R = 1 - \frac{1,295}{\log_2 3} = 1 - \frac{1,295}{1,585} = 1 - 0,817 = 0,183 \ (18,3\%)$.

*Вывод:* текст обладает избыточностью в 18,3%, что позволяет сжать его алгоритмом Хаффмана на 18,3% и указывает на уязвимость к частотному криптоанализу.

**1.3 Математическое доказательство (неравенство Йенсена):**

Применим неравенство Йенсена $\sum p_i f(x_i) \le f\left(\sum p_i x_i\right)$ для $f(x)=\log_2(x)$:

$$H(X) = 0,6 \log_2\left(\frac{1}{0,6}\right) + 0,3 \log_2\left(\frac{1}{0,3}\right) + 0,1 \log_2\left(\frac{1}{0,1}\right) \le \log_2\left(0,6 \cdot \frac{1}{0,6} + 0,3 \cdot \frac{1}{0,3} + 0,1 \cdot \frac{1}{0,1}\right) = \log_2(3)$$

Т.к. $0,6 \neq 0,3 \neq 0,1$, распределение неравномерно. Для строго вогнутой функции неравенство обращается в равенство только при $p_1=p_2=p_3$. Следовательно, $H(X) < \log_2(3)$. Доказано.

#### Задание 2. Двукратное использование OTP

**2.1 Математическое доказательство $C_1 \oplus C_2 = M_1 \oplus M_2$:**

Дано: $C_1 = M_1 \oplus K$, $C_2 = M_2 \oplus K$.
Сложим шифротексты по модулю 2:

$$C_1 \oplus C_2 = (M_1 \oplus K) \oplus (M_2 \oplus K).$$
Т.к. операция $\oplus$ ассоциативна и коммутативна, а $K \oplus K = 0$:

$$C_1 \oplus C_2 = M_1 \oplus M_2 \oplus (K \oplus K) = M_1 \oplus M_2 \oplus 0 = M_1 \oplus M_2.$$

Доказано.

**2.2 Доказательство потери совершенной секретности:**

Совершенная секретность требует: $H(M_1, M_2 \mid C_1, C_2) = H(M_1, M_2)$.
Из п. 2.1 злоумышленнику известна величина $\Delta = C_1 \oplus C_2 = M_1 \oplus M_2$.
Тогда 

$$M_2 = M_1 \oplus \Delta.$$

Условная энтропия: 

$$H(M_1, M_2 \mid C_1, C_2) = H(M_1 \mid C_1, C_2) + H(M_2 \mid M_1, C_1, C_2).$$

Поскольку при известном $M_1$ и $\Delta$ (которая известна из $C_1, C_2$) значение $M_2$ определяется однозначно, $H(M_2 \mid M_1, C_1, C_2) = 0$. Следовательно:

$$H(M_1, M_2 \mid C_1, C_2) = H(M_1 \mid C_1, C_2) \le H(M_1).$$

Так как для независимых нетривиальных сообщений $H(M_1) < H(M_1) + H(M_2)$, то:
$H(M_1, M_2 \mid C_1, C_2) \le H(M_1) < H(M_1, M_2)$.
Стойкость Шеннона нарушена (апостериорная неопределенность строго меньше априорной). Доказано.

#### Задание 3. Энтропия Марковского источника

Дано: $P_{11} = 0,7$, $P_{22} = 0,4$.
Тогда 
$$P_{12} = 1 - 0,7 = 0,3,$$
$$P_{21} = 1 - 0,4 = 0,6.$$

**3.1 Стационарное распределение:**

$$\pi_1 = \pi_1(0,7) + \pi_2(0,6) \implies 0,3\pi_1 = 0,6\pi_2 \implies \pi_1 = 2\pi_2.$$

Т.к.

$$\pi_1 + \pi_2 = 1 \implies 2\pi_2 + \pi_2 = 1 \implies \pi_2 = \frac{1}{3} \approx 0,333$, $\pi_1 = \frac{2}{3} \approx 0,667.$$

**3.2 Условные энтропии состояний:**

$$H(X \mid S_1) = -(0,7 \log_2 0,7 + 0,3 \log_2 0,3) = -(0,7 \cdot (-0,515) + 0,3 \cdot (-1,737)) = 0,36 + 0,521 = 0,881 /text{бит.}$$ 
$$H(X \mid S_2) = -(0,6 \log_2 0,6 + 0,4 \log_2 0,4) = -(0,6 \cdot (-0,737) + 0,4 \cdot (-1,322)) = 0,442 + 0,529 = 0,971 /text{бит.}$$ 

**3.3 Предельная энтропия:**

$$H_{\infty}^{Markov} = \frac{2}{3}(0,881) + \frac{1}{3}(0,971) = 0,587 + 0,324 = 0,911 \text{ бит/символ.}$$

*Сравнение с источником без памяти* (распределение $\pi_1=2/3, \pi_2=1/3$):

$$H(X) = -(\frac{2}{3} \log_2 \frac{2}{3} + \frac{1}{3} \log_2 \frac{1}{3}) = 0,918 \text{бит/символ.}$$

*Вывод:* $0,911 < 0,918$ наличие памяти у источника (зависимости от предыдущего символа) снижает неопределенность системы.

#### Задание 4. Минимальная энтропия Реньи

Для распределения $p_1 = 0,6, p_2 = 0,3, p_3 = 0,1$:

Максимальная вероятность $\max p_i = 0,6$.

$$H_{\infty}(X) = -\log_2(0,6) \approx 0,737 \text{бит.}$$

*Обоснование:* энтропия Шеннона составила 1,295 бит, min-энтропия (0,737 бит) строго меньше. Для злоумышленника, осуществляющего словарную атаку, важнейшим фактором является вероятность угадывания самого популярного пароля с первой попытки. $H_{\infty}(X)$ дает консервативную оценку стойкости именно против оптимальной стратегии угадывания, поэтому в ИБ она предпочтительнее.

#### Задание 5. Расстояние единственности для AES

Дано: $H(K) = 128$ бит, $A = 32$, $R = 0,68$.

$$U = \frac{128}{0,68 \cdot \log_2(32)} = \frac{128}{0,68 \cdot 5} = \frac{128}{3,4} \approx 37,64 \text{ символа (байта).}$$

*Обоснование:* если криптоаналитик перехватит 38 байт шифротекста AES, он может запустить полный перебор всех $2^{128}$ ключей. Большинство неверных ключей расшифруют текст в случайный мусор (без избыточности). Благодаря избыточности английского языка ($R=0,68$), длины 38 байт теоретически достаточно, чтобы статистический анализатор отсеял все ложные ключи и оставил один истинный открытый текст.
